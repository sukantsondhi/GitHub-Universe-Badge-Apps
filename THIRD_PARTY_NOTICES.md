## Existing firmware material

The bundled fonts, icons and character sprite sheets under [assets](assets),
and the reference [main.py](main.py), originate from or relate to the GitHub
Universe badge/Mona-OS distribution. The upstream project is
[badger/home](https://github.com/badger/home), with the relevant firmware release
[Mona-OS v4.03](https://github.com/badger/home/releases/tag/mona-os-v4.03).

All **45 tracked files** in this group were compared by Git blob hash and match
the `badge/` files in Mona-OS v4.03 byte-for-byte. That release is distributed
under the MIT license, with attribution to GitHub. Its full notice is retained
in [docs/licenses/mona-os-MIT.txt](docs/licenses/mona-os-MIT.txt), from the
[upstream release license](https://github.com/badger/home/blob/mona-os-v4.03/LICENSE).

Retain that notice when redistributing these files. The application-code
license does not replace upstream attribution. This provenance check does not
grant trademark rights or imply GitHub/Pimoroni endorsement. The custom apps
normally use the fonts already installed on the badge.

The locally supplied Pikachu test GIF is ignored and has not been added to the
public file set. This preserves the local copy without asserting redistribution
permission. Do not force-add it without permission.

## Generated documentation media

The geometric demo animation is generated by
[tools/render_readme_images.py](tools/render_readme_images.py). UI screenshots
use the project's interface and fictional data, not downloaded test GIFs,
personal photos or real Wi-Fi/pairing configuration. Badge illustrations use
substitute system fonts; those fonts are not embedded as font files in the images.
